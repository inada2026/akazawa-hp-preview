よくあるこまりごと

Q1　「codex」と打っても出てきません

MacにCodexが入っていないのかもしれません。そのときは、インターネットのChatGPTで聞けます。

① ⌘＋スペース → safari と打って return
② 上の細長い欄をクリックして chatgpt.com と打って return
③ 下の欄に「こまったときの文」か「その2（作り直して）」をはって、おくる

ChatGPTはMacの中はさがせませんが、作り直しや、とり戻し方の説明はしてくれます。「Macで保存しないで閉じたKeynoteの資料をとり戻す方法を、1つずつ教えて」と聞いてみてください。

Q2　⌘とスペースを押しても、さがす窓が出ません

⌘を先に押して、指をはなさずにスペースを押してみてください。同時だとうまくいかないことがあります。

それでもだめなら、画面の右上の虫めがねのマークをクリックしても、同じ窓が出ます。

Q3　「ログイン」と出ました

いつもChatGPTで使っているメールアドレスでログインします。「Googleで続ける」や「Appleで続ける」のボタンがあれば、それをクリックすると楽です。

Q4　「GPT-6.1 Sol 軽」の直し方がわかりません

Codexに「モデルをGPT-6.1 Solにして、考える量を『軽』にしたいです。どこをクリックすればいいか、1つずつ教えてください」と聞いてみてください。うまくできなくても、さがす作業はできるので大丈夫です。

Q5　Codexの返事が英語です／むずかしいです

「日本語で、中学生にもわかるように言いなおしてください」と打っておくってみてください。

Q6　ずっと動いていて、終わりません

文字が流れていたり、くるくる回るマークが出ていたら、ちゃんと動いています。10分たっても変わらなければ「まだですか？いまわかっていることだけ教えてください」とおくってみてください。

Q7　デスクトップが見えません

画面の一番下にならんでいるアイコンから、青と白の顔のマーク（Finder）をクリック。左の列の「デスクトップ」をクリックすると、中に「復元候補」があります。

Q8　「削除していいですか」と聞かれました

「いいえ」で大丈夫です。Codexに「何も消さないでください」とおくってください。

Q9　パスワードを聞かれました

灰色の小さな窓で聞かれたら、いつもMacを開くときのパスワードを入れます。Codexの欄には、パスワードは打たないでくださいね。

キーボードの右上の、指紋のボタンに指をのせるだけでいいこともあります。

Q10　「フルディスクアクセス」と言われました

Codexに「フルディスクアクセスの入れ方を、1つずつ教えてください」とおくると、順番に教えてくれます。

自分でやるときは：左上のりんごマーク → システム設定 → プライバシーとセキュリティ → フルディスクアクセス → Codexの横のスイッチをクリックして青くする。

Q11　候補がたくさんあって、どれかわかりません

「一番新しくて、スライドが一番多いのはどれ？」と聞いてみてください。開くだけなら、何もこわれません。ちがったら閉じて、次を開けば大丈夫です。

Q12　とちゅうまでしか残っていませんでした

まず手順5Aのとおり保存します。そのあとCodexに「この資料のつづきを作ってください。つづきの中身は【思い出せること】です」とおくってみてください。

Q13　ファイルが開けません

Codexに「復元候補の資料が開けません。中の文字だけでも出せますか」とおくってみてください。

Q14　まちがえて、へんなところをクリックしたかも

大丈夫です。最初の文で「消さないで」とたのんであります。Codexに「まちがえて何か押したかもしれません。大丈夫ですか」と聞いてみてください。

Q15　もうつかれました。今夜は最低限にしたいです

「その1」をおくるだけおくって、寝てしまっても大丈夫です。Codexの返事は画面に残っています。Macのふたは開けたままにしておいてくださいね。朝、つづきから読めばいいですよ。
