保存せずに閉じた資料、
Codexに探してもらいましょう

まだ残っている可能性があります。Macは、保存ボタンを押していなくても、裏でこっそり控えを取っていることが多いからです。

探すのはCodex（コーデックス）にお願いします。このページの文をコピーして貼るだけです。難しい操作はありません。

かかる時間：10分くらい
見つからなかった場合も、Codexに作り直しを頼む方法を書いてあります（手順5）。明日のセミナーには間に合わせられます。

目次：1 Codexを開く ／ 2 文を貼る ／ 3 「許可」を聞かれたら ／ 4 見つかったら ／ 5 見つからなかったら ／ 困ったとき（質問集）

先に、これだけ

新しい資料を作り始めないでください

KeynoteやPowerPointで新しい資料を作って保存すると、控えが上書きされて消えることがあります。探し終わるまでは、そのソフトで新しい作業をしないでおいてください。

Canva（キャンバ）やGoogleスライドで作っていた場合は、Codexはいりません。
この2つは、ネットの上で自動で保存されています。Canvaなら開いて「最近のデザイン」、Googleスライドならこちらを開くと、一番上に出てきます。

1Codexを開く

  1. キーボードの ⌘ command を押したまま スペース を押します。画面の真ん中に検索の窓が出ます。
  2. codex と打って、return を押します。
  3. Codexの画面が開きます。下のほうに、文字を打つ欄があります。

画面の一番下に並んでいるアイコン（Dock）にCodexがあれば、そこをクリックしても開けます。

「どのフォルダで作業しますか」と聞かれたら、家のマーク（ご自分の名前）のフォルダを選んでください。

2下の文をコピーして、Codexに貼って送る

  1. 下の青いボタン「この文をコピー」を押します。
  2. Codexの文字を打つ欄をクリックして、⌘ command を押したまま V を押します（貼り付け）。
  3. 【　】の中だけ、わかる範囲で書きかえます。わからなければ、そのままで大丈夫です。
  4. return を押して送ります。
Codexに送る文（その1：探す）
保存しないで閉じてしまった資料を探してほしいです。私はパソコンに詳しくないので、やさしい日本語でお願いします。

・閉じてしまったのは、10月22日の夜22時ごろです
・明日のセミナーで使う資料です
・使っていたソフト：【Keynote／PowerPoint／わからない】
・資料の名前：【わかれば書く。わからなければ「わからない」】

お願いしたいこと：
1. このMacの中から、ここ3日以内に作ったり変わったりした資料のファイル（Keynote、PowerPoint、Pages、Word、PDFなど）を探してください。KeynoteやPowerPointの「自動保存」「自動回復」の置き場所、iCloud Drive、ゴミ箱、一時ファイルの置き場所も見てください。
2. 見つかったものは、デスクトップに「復元候補」というフォルダを作って、そこにコピーしてください。
3. 元のファイルは、動かさない・消さない・上書きしないでください。
4. 見つかったファイルについて、名前・最後に変わった時刻・スライドが何枚くらいか、を教えてください。一番それらしいものはどれか、も教えてください。
5. 私が何か操作する必要があるときは、押すボタンを1つずつ順番に教えてください。

送ったら、Codexが探し始めます。数分かかることがあります。そのまま待ってください。

3「許可しますか」と聞かれたら

Codexが探している途中で、確認の小さな窓が出ることがあります。

押していいもの
「許可」「承認」「OK」「はい」
英語なら Allow／Approve／Yes
（探す・見る・コピーする、のための確認です）
押さないもの
「削除」「上書き」「消去」と書いてあるとき
英語なら Delete／Remove／Overwrite
（このときは「いいえ」か「拒否」）

Mac本体から「"Codex"が、ほかのアプリからのデータへのアクセスを求めています」と出たら、「許可」を押してください。KeynoteやPowerPointの控えを見るために必要です。

「フルディスクアクセス」という言葉が出てきたら、下の質問集の「フルディスクアクセスと言われた」を見てください。

4見つかったら

  1. デスクトップに「復元候補」というフォルダができています。ダブルクリックで開きます。
  2. Codexが「一番それらしい」と言ったファイルをダブルクリックして開きます。
  3. 「復元しますか」と出たら「復元」（または「はい」）を押します。
  4. 中身を確かめたら、すぐに保存します。画面の一番上の「ファイル」→「保存」（または「別名で保存」）を押して、わかりやすい名前（例：セミナー資料_1023）をつけ、場所を「書類」にして保存します。
これで完了です。お疲れさまでした。
途中までしか残っていなかったときは、手順5の「作り直し」で、足りない部分だけCodexに頼めます。

5見つからなかったら（作り直しをCodexに頼む）

覚えていることを、思いつくまま書いて送るだけで、Codexが資料の下書きを作ってくれます。きれいな文になっていなくて大丈夫です。

Codexに送る文（その2：作り直す）
資料は見つからなかったので、作り直したいです。下に覚えていることを書くので、明日のセミナーで使えるスライド資料を作ってください。

・セミナーの日時：明日【　】時から【　】分くらい
・来る人：【例：経営者の方、10人くらい】
・セミナーの題名：【わかれば】
・使いたいソフト：【Keynote／PowerPoint／どちらでもいい】

覚えている中身（順番がばらばらでもいいです）：
【ここに思い出せることを書く】

お願い：
1. 1枚に書く文字は少なめにして、読みやすくしてください。
2. できたファイルはデスクトップに保存して、場所と名前を教えてください。
3. 私が足したほうがいいところ（具体的な例や数字など）があれば、最後に箇条書きで教えてください。

できあがったら、デスクトップのファイルをダブルクリックして開き、直したいところは「3枚目の文を短くして」のようにCodexに話しかければ直してくれます。

Codexの返事が難しかったとき

専門用語ばかりで、何をすればいいかわからない返事が来たら、これを送ってください。

Codexに送る文（その3：やさしく言い直して）
今の説明は難しくてわかりませんでした。パソコンに詳しくない人向けに、次に私が押すボタンを1つだけ教えてください。英語の言葉は使わないでください。

困ったとき（質問集）

気になるところをクリックすると、答えが開きます。

Codexを開くまで

⌘とスペースを押しても、検索の窓が出ません

⌘（command）はスペースバーのすぐ左右にあるキーです。⌘を先に押して、押したままスペースを押してください。同時に押すとうまくいかないことがあります。

それでも出ないときは、画面の右上にある虫めがねのマークをクリックしても同じ窓が出ます。

「codex」と打っても出てきません

カタカナで「コーデックス」と打っても出ないときは、CodexではなくChatGPT（チャットジーピーティー）のアプリが入っているかもしれません。「chatgpt」と打って探してみてください。

ChatGPTのアプリだけの場合は、Macの中は探せません。下の「ChatGPTしかなかった」を見てください。

ChatGPTしかなかった

ChatGPTはMacの中のファイルを見られないので、探すのはご自分でやる形になります。ChatGPTに「Macで、保存しないで閉じた【Keynote／PowerPoint】の資料を取り戻す方法を、パソコンに詳しくない人向けに1つずつ教えて」と聞いてください。順番に教えてくれます。

作り直しは、ChatGPTでもできます。手順5の「その2」の文をそのまま貼ってください（最後の「デスクトップに保存して」の部分は、ChatGPTの画面からダウンロードする形になります）。

「ログインしてください」と出ました

いつも使っているChatGPTのアカウント（メールアドレス）でログインしてください。パスワードがわからないときは、無理せず明日の朝に稲田に連絡してください。

「どのフォルダで作業しますか」「フォルダを選択」と出ました

左側の一覧から、家のマーク（ご自分の名前）のフォルダを選んで「開く」を押してください。Mac全体の資料を探しやすくなります。

送ったあと

返事が英語で来ました

「日本語で答えてください」と送ってください。

ずっと動いていて、終わりません

Mac全体を探すので、5分くらいかかることもあります。画面で文字が流れていたり、くるくる回るマークが出ていたりすれば、ちゃんと動いています。

10分たっても変わらないときは、「まだ探していますか？今わかっていることだけ教えてください」と送ってください。

小さな窓がたくさん出てきて、こわいです

Codexが「ここを見てもいいですか」と一つずつ確認しているだけです。「削除」「上書き」と書いていなければ、「許可」で大丈夫です。最初の文で「消さない・上書きしない」とお願いしてあります。

Codexに「削除していいですか」と聞かれました

「いいえ」です。「何も消さないでください。コピーだけにしてください」と送ってください。

「フルディスクアクセス」と言われました

Macの中の深いところまで見るための許可です。Codexがそう言ったときだけ、次のとおりにしてください。

  1. 画面の左上のりんごのマークをクリック
  2. 「システム設定」をクリック
  3. 左の一覧から「プライバシーとセキュリティ」をクリック
  4. 右側の「フルディスクアクセス」をクリック
  5. 一覧の中のCodexの右にあるスイッチをオンにする（青くなればオン）
  6. Macのパスワードを聞かれたら、いつもMacを開くときのパスワードを入れる
  7. Codexに戻って「許可しました。続けてください」と送る

Codexが一覧にないときは、無理にやらなくて大丈夫です。「フルディスクアクセスはできませんでした。見られる範囲で探してください」と送ってください。

パスワードを聞かれました

Mac本体が出す窓（灰色の小さな窓）なら、いつもMacを開くときのパスワードを入れてください。

Codexの文字を打つ欄には、パスワードを書かないでください。そこに書く必要はありません。

使っていたソフトが、KeynoteかPowerPointかわかりません

「わからない」のままで大丈夫です。Codexが両方とも探します。

思い出す手がかり：画面の一番上、りんごのマークのすぐ右に出ていた名前がソフトの名前です。オレンジ色のアイコンならPowerPoint、青い演台のアイコンならKeynoteです。

見つかったとき

候補がいくつも見つかって、どれかわかりません

「一番新しくて、スライドの枚数が一番多いのはどれですか」と聞いてください。それから開いてみて、違っていたら次を開けばいいです。開くだけでは何も壊れません。

開いたら、途中までしか残っていませんでした

それでも大きな前進です。まず手順4のとおりすぐ保存してから、Codexに「このファイルは○枚目までしか残っていませんでした。続きは【覚えていること】です。続きのスライドを足してください」と送ってください。

ファイルが開けません／「壊れています」と出ます

Codexに「デスクトップの復元候補の【ファイル名】が開けません。中の文字だけでも取り出せますか」と送ってください。文字が取り出せれば、そこから作り直せます。

「復元」と「削除」の両方のボタンが出ました

「復元」を押してください。

保存の場所がよくわかりません

保存の窓で、場所の欄を「書類」か「デスクトップ」にしておけば、あとで見つけやすいです。わからなければ、Codexに「今開いている資料を、デスクトップに『セミナー資料_1023』という名前で保存したい。どこを押せばいいか1つずつ教えて」と聞いてください。

見つからなかったとき

Codexが「見つかりませんでした」と言いました

念のため1回だけ、「Time Machine（タイムマシン）のバックアップや、iCloudの『最近削除した項目』も見てください」と送ってみてください。それでもなければ、手順5の作り直しに進みましょう。

作り直すほど、内容を覚えていません

単語だけで大丈夫です。たとえば「自己紹介、経営者の悩み、部下との関係、質問のしかた3つ、最後に案内」のように並べるだけでも、Codexが話の流れを組み立ててくれます。

前に使った似た資料がMacにあれば、「前のセミナーの資料を探して、それをもとに作ってください」と頼むこともできます。

作り直しにどれくらいかかりますか

下書きができるまで、だいたい5〜15分くらいです。そのあと、気になるところを話しかけて直していきます。

できた資料のデザインが好みではありません

「白と水色を中心に、落ち着いた感じにしてください」「文字をもっと大きくしてください」のように、言葉で頼めば直してくれます。

そのほか

変なところを押してしまったかもしれません

最初の文で「消さない・上書きしない」と頼んであるので、元のファイルが消えることはまずありません。落ち着いて、Codexに「今、間違えて何か押したかもしれません。何か変わりましたか」と聞いてください。

もう疲れました。今夜は最低限だけにしたいです

手順2の「その1」の文を送るだけ送って、寝てしまっても大丈夫です。Codexは探し続けて、結果を画面に残しておいてくれます。Macのふたは開けたままにしておいてください。

朝に結果を見て、わからなければ稲田に連絡してください。

次から、こうならないようにするには

資料を作り始めたら、最初に1回だけ名前をつけて保存してください。（⌘を押したまま S）

KeynoteもPowerPointも、一度名前をつけて保存したファイルは、そのあと自動で保存され続けます。保存せずに閉じても消えなくなります。

どうしてもうまくいかないときは、明日の朝、稲田にLINEしてください。一緒に見ます。
